# 개인정보 처리방침

**Picnique Smart Ring**(이하 「앱」)은 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」 등 관련 법령을 준수합니다.  
본 방침은 앱이 어떤 정보를 수집·이용·보관·파기하는지 설명합니다.

> **시행일:** 2026년 6월 1일  
> **최종 개정일:** 2026년 6월 1일  
> **개인정보 보호책임자:** 홍범기 / ceo@picnique.kr

---

## 1. 수집하는 개인정보 항목 및 방법

### 1.1 수집 항목

| 구분 | 항목 | 수집 목적 |
|------|------|-----------|
| **필수** | 스마트링 기기 식별 정보(블루투스 주소·기기명 등) | 기기 연결·재연결·연결 상태 표시 |
| **필수** | 건강·활동 데이터(심박수, 혈중 산소 포화도, 스트레스 지수, 수면, 걸음수, 칼로리, 이동 거리 등) | 건강 상태 확인·기록·통계 제공 |
| **선택** | 계정 정보(이메일, 비밀번호 등) — 로그인 기능 사용 시 | 회원 식별·서비스 제공·고객 지원 |
| **선택** | 문의·버그 신고 시 입력 정보(이름, 연락처, 문의 내용 등) | 문의 응대·품질 개선 |
| **자동** | 기기 정보(OS 버전, 앱 버전), 서비스 이용 기록, 오류 로그 | 서비스 안정화·보안·품질 개선 |

앱은 **의료기기가 아니며**, 수집된 건강 데이터는 **참고용 웰니스 정보**로만 제공됩니다. 진단·치료 목적으로 사용되지 않습니다.

### 1.2 수집 방법

- 앱 설치·실행, 스마트링 연결, 건강 데이터 동기화
- 설정·문의·버그 신고 화면에서 이용자가 직접 입력
- 서비스 이용 과정에서 자동 생성·수집

---

## 2. 개인정보의 이용 목적

회사는 수집한 정보를 다음 목적 범위에서만 이용합니다.

1. 스마트링 연결·유지·배터리 부족 등 **알림** 제공  
2. 건강·활동 데이터 **조회·저장·통계·시각화**  
3. **백그라운드 동기화**를 통한 데이터 누적(앱 미실행 시 포함)  
4. 가톨릭·묵주기도 등 **부가 기능** 제공(해당 기능 이용 시)  
5. 서비스 **품질 개선**, 오류 분석, **고객 문의** 처리  
6. 법령에 따른 **의무 이행**

## 3. 개인정보의 보유 및 이용 기간

| 항목 | 보유 기간 |
|------|-----------|
| 스마트링 연결 정보 | 연결 해제 또는 앱 삭제 시까지(기기 내 저장 설정에 따름) |
| 건강·활동 데이터(기기 내) | 이용자가 삭제하거나 앱 삭제 시까지 |
| 서버 전송 데이터(해당 시) | [보유 기간 명시, 예: 회원 탈퇴 후 30일 이내 파기] |
| 문의·버그 신고 | 처리 완료 후 [예: 3년] |

관계 법령에 따라 보존이 필요한 경우 해당 기간 동안 보관합니다.

## 4. 개인정보의 제3자 제공

회사는 원칙적으로 이용자의 개인정보를 **제3자에게 제공하지 않습니다.**  
다만 아래의 경우는 예외로 합니다.

- 이용자가 **사전에 동의**한 경우  
- 법령에 근거하거나 수사·조사 목적으로 법령에 정한 절차와 방법에 따라 요청이 있는 경우

> **참고:** 앱에 외부 건강·복지 플랫폼 연동이 있는 경우, 해당 서비스명·제공 항목·목적을 여기에 별도 명시하세요.  
> 예: `[플랫폼명]` — 전송 항목: `[항목]` / 목적: `[목적]`

## 6. 이용자의 권리와 행사 방법

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

- 개인정보 **열람·정정·삭제** 요청  
- 처리 **정지** 요청  
- **동의 철회**(선택 항목에 한함)

**행사 방법:** 앱 내 설정 → 문의하기, 또는 ceo@picnique.kr 로 요청  
회사는 지체 없이 조치하며, 법령에 따른 제한이 있는 경우 그 사유를 안내합니다.

## 7. 개인정보의 파기

보유 기간이 경과하거나 처리 목적이 달성된 경우 **지체 없이 파기**합니다.

| 구분 | 방법 |
|------|------|
| 전자적 파일 | 복구·재생이 불가능한 방법으로 영구 삭제 |
| 출력물 등 | 분쇄 또는 소각 |

앱 삭제 시 기기에 저장된 로컬 데이터는 OS·이용자 설정에 따라 제거될 수 있습니다.

## 8. 개인정보의 안전성 확보 조치

회사는 개인정보 보호를 위해 다음 조치를 취합니다.

- 접근 권한 관리 및 최소 권한 원칙  
- 전송 구간 **암호화**(HTTPS 등, 서버 연동 시)  
- 악성코드 방지·보안 업데이트  
- 개인정보 취급자 **교육** 및 내부 관리 계획 수립

## 9. 앱 권한 안내

앱은 기능 제공을 위해 아래 권한을 요청할 수 있습니다. **필요 최소한**으로만 사용합니다.

| 권한 | 용도 | 필수 여부 |
|------|------|-----------|
| 블루투스 | 스마트링 검색·연결·데이터 수신 | 필수 |
| 위치(Android) | 블루투스 기기 검색( OS 정책) | 필수(Android) |
| 알림 | 배터리 부족·서비스 유지 알림 | 선택 |
| 백그라운드 실행·배터리 최적화 예외 | 연결 유지·주기적 데이터 수집 | 선택 |

권한 거부 시 일부 기능(연결, 알림, 백그라운드 동기화 등)이 제한될 수 있습니다.
